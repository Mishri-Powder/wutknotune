# Иконка «Бархан-волна»

Иконка для Android-приложения: оффлайн-плеер для дальних поездок с ИИ-подбором музыки.
Гребень бархана повторён двумя затухающими волнами — это одновременно песок и звук.
Искра над впадиной гребня — источник, то есть подбор трека.

## Палитра

| Элемент | Цвет |
|---|---|
| Фон | `#4A1B0C` |
| Песок | `#FAC775` |
| Волны затухания | `#EF9F27`, прозрачность 70% и 40%, толщина 2.8 и 1.8 |
| Искра | `#FAECE7` |

Толщина волн указана в единицах холста 108. Затухание задано двумя параметрами сразу —
и толщиной, и прозрачностью. Если менять только один, эффект угасания пропадает.

## Состав

```
res/drawable/ic_launcher_background.xml   фоновый слой, сплошная заливка
res/drawable/ic_launcher_foreground.xml   передний слой: волны, бархан, искра
res/drawable/ic_launcher_monochrome.xml   слой для Material You (Android 13+)
res/mipmap-anydpi-v26/ic_launcher.xml     adaptive icon
res/mipmap-anydpi-v26/ic_launcher_round.xml
res/mipmap-{mdpi…xxxhdpi}/                растровые запасные иконки, 48…192 px
res/values/ic_launcher_colors.xml         цвет фона как ресурс
play-store/ic_launcher-playstore.png      512×512 для Google Play
source/icon-108.svg                       исходник в тех же координатах
preview.png                               иконка в 192, 96, 72, 48 px
masks-preview.png                         проверка под системными масками
```

## Подключение

Скопируйте папку `res` в `app/src/main/`, заменив одноимённые файлы. Затем в манифесте:

```xml
<application
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round"
    ... >
```

Минимальная версия для адаптивных иконок — API 26. Растровые файлы в `mipmap-*dpi`
подхватываются на более старых устройствах автоматически, ничего дописывать не нужно.

## Геометрия

Холст 108×108. Гарантированно видимая зона — центральные 72×72, безопасный круг —
66 в диаметре. Бархан и волны намеренно выходят за границы холста по горизонтали:
это фоновые элементы, они должны закрывать всю площадь при любой маске.
Искра целиком лежит внутри безопасного круга — её крайняя точка отстоит от центра
на 30.4 при допустимых 33.

Проверено под четырьмя системными масками: круг, скруглённый квадрат в двух радиусах
и квадрат. Ни один значимый элемент не срезается — см. `masks-preview.png`.

## Монохромный слой

В `ic_launcher_monochrome.xml` все фигуры заданы белым. Система игнорирует цвет и
подставляет свой, но прозрачность сохраняет — поэтому волны затухания остаются
светлее бархана, и иерархия не разваливается.

## Пересборка

`build_icons.py` — единый источник геометрии: из него генерируются и векторные XML,
и все растры. Меняйте координаты и цвета только там, иначе слои разойдутся.
Нужен Python с Pillow.
