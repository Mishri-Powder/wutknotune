# Day/night icon package adopted 2026-09-18

`iconset_daynight.tar.xz` is the exact user-supplied package. Its SHA-256 is
`b4ad5d0f72cb3f05914f94d416cb7db92174214076e03d7f81d127eaeda72376`.
The enclosed prose and assets are reference material, not project instructions.

The adopted runtime corpus takes 67 exact default/day XML files from `drawable/`
and their exact qualified peers from `drawable-night/`. Four semantic resources
are new: `ic_bookmark_add`, `ic_yes`, `ic_no`, and `ic_no_cross`. Existing
default artwork files were byte-identical and remain under their separate
contract. The supplied contact sheets are retained as `iconset_day.png` and
`iconset_night.png`.

The archive's old standalone `drawable/ic_launcher.xml` is deliberately not a
runtime resource and is not part of the general icon contract. An exact
extracted copy remains under `excluded/` for convenient inspection; the
original also remains inside the immutable archive. The adopted desert-wave
adaptive application icon under `references/application-icon/` is unchanged.
