# Contract reference catalog

**Snapshot baseline:** 2026-10-05 (America/Los_Angeles). Affected audiobook speed and refactor pages
were refreshed on 2026-10-09; release-audit and recovery updates were refreshed on 2026-10-10. A-Z
filter-save contracts and delivery were refreshed on 2026-10-12.

**Status:** Reference-only catalog. The [project Wiki](https://wiki.271.pics/Riff) remains the
authoritative documentation; changes to a requirement belong in its owning Wiki contract first.

This catalog contains selected current contracts and supporting records: 107 Riff pages, 15 Cuetree
pages and 44 Cuegrain pages. The directory layout mirrors Wiki routes, so
`Riff/LATEST/player-queues.md` corresponds to `/Riff/LATEST/player-queues`. Included pages may link
to local Markdown or the Wiki. Pages refreshed under the publication gate preserve their current
Wiki contents; older catalog exports may omit implementation-status sections. The catalog is an
incremental reference snapshot, not a complete export of every current Wiki record.

Start with [the Riff requirements registry](Riff/LATEST/requirements.md), the
[Cuetree contract](Cuetree/contract.md) or the [Cuegrain contract](Cuegrain/contract.md).
[Rejected design options](REJECTED_DECISIONS.md) collect current prohibitions in one place; each
entry links to its controlling contract.
