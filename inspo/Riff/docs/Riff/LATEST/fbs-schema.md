# Riff data-format registry

- [Cuetree persistence](../../Cuetree/persistence.md) owns MDIA, ALBM, ARTS and GNRV, their format
  version and coherent library cohort.
- [MDRG](format-mdrg.md) owns the optional Cuetree-keyed AI/ReplayGain snapshot and its independent
  generation.
- [GNRE](format-gnre.md) owns the static genre dictionary packaged in the APK.

[Cuetree integration](cuetree-integration.md) owns Android adaptation;
[immutable publication](immutable-publication.md) owns delivery. [Player storage](player-storage.md)
owns mutable profile and playback data.
