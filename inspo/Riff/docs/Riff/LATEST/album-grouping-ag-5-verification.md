# Riff Album grouping contract — AG-5 Verification

> Owner/scope: RIFF-ALBUM-V2 acceptance and consumer boundaries.

## AG-5 Verification

Verify global metadata grouping using complete exported cohorts, not only visible UI rows or a
rescan whose identities may differ. Distinguish measured current membership from host-model
predicted membership. Validate binary manifests, headers and references before schema-shaped JSON
conversion; keep 64-bit IDs exact. A source export is private diagnostic material unless separately
approved for publication. Do not modify the working library while evaluating alternatives.

Acceptance fixtures include scattered numbered partial compilations (seven Breakbeat Kaos tracks,
thirteen of nineteen Крылья-2003 positions), unnumbered same-year soundtracks (twelve Lost In
Translation-OST tracks and seven Kill Bill Volume 2 tracks), five distinct Greatest Hits artist
albums from the full export, and a single-artist Tragic Kingdom album relocated across unrelated
directories. Expect one album per compilation/single-artist fixture and five separate Greatest Hits
groups. Absence of Album without explicit structure goes to Singles; ambiguous assignment must not
bridge editions. A genuinely independently admitted singleton remains a valid album.

Disc-family tests include CD1/CD-2/[Disc 03]/Диск 4; whitespace, case and zero padding; CD9/CD10;
more than two discs; missing ordinals; duplicate ordinal folders; conflicting Disc tags; year/MP3
numbers; differing edition suffixes; multiple numeric interpretations; and distinct parents/volumes.
Folder ordinals can order/partition missing-Disc members without creating stored tags or totals.

Verify absent/invalid/conflicting totals, unresolved and proven slot collisions, equivalent copies,
artist-component sets, unknown-field bridges, generic Various Artists, equal-strength alternatives,
and the accepted indistinguishable same-title/year compilation heuristic. Permuting traversal order
must preserve membership and position order. Relocation must preserve metadata-established groups.

Explicit CUE/TOC ownership, untitled chapter expansion and fallback, repeated explicit positions,
retained unavailable facts, TTL, cancellation, catalog IDs, reciprocal ARTS/GNRV references, and
every intermediate/final publication remain required. Validate Cuetree output, desktop JSON and
Player consumption together. No format migration or compatibility reader is adopted.

Additional acceptance includes terminal Album CD1/CD2 normalization only inside a corroborating
family; an unsuffixed first-disc Album; meaningful Original/Demos titles staying distinct; rejection
of CD 3T with no numeric-fallback bypass; and real four/five-disc families.

Verify a single bad slot without global clustering shutdown, equal Media.ID at different declared
positions, same-position copies, unequal-ID variants without deletion, overlapping editions with
unknown Disc, and separate one-track concerts despite a residual score above threshold. Placeholder
equality must not create artist/year proof; mixed artist component sets retain their factual values.

The adopted format must reject the preceding version even when its schema layout remains decodable.
Verify full factual/projection/MDRG recreation, preservation of Player state and generation
watermarks, normal L0/L1/L2 restart, and no compatibility reader or partial catalog conversion.
Strictly parse every JSON companion with control-bearing strings and exact 64-bit IDs.

Bound working memory without allocating a full candidate-pair matrix. Verify cancellation and
publication under large residual as well as structural candidates; a structural-only host timing is
not an Android throughput or residual scalability guarantee.

## AG-6 Content-mode consumer boundary

[Content modes](/Riff/LATEST/player-content-mode) own profile filtering and any-member Book
promotion. Indexer grouping neither reads profiles nor reruns because a mode/override changes.
Titles/Authors consume the same ready catalogs. Missing Album remains ineligible for ordinary
grouping. Contextual missing-tag inference MAY-INDEXER-01 remains deferred; directory disc scope is
transient grouping evidence, not a factual tag write.
