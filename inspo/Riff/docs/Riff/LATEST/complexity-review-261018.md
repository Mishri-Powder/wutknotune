# Riff complexity review — 2026-10-18

This is an engineering assessment, not a replacement specification. The comparisons below use
primary project and platform documentation checked on 2026-10-18. The judgments are inferences:
there is no universal player architecture against which every different implementation is wrong. A
simpler alternative is useful only if it preserves the author's adopted behavior and operating
conditions. Recommendations here do not authorize removing a requirement.

## Priorities

First keep the corrected failure boundaries: a cancellation fence must wait for the writer, and an
access error must not become corruption. Next measure cold-start memory/time and decoder-calibration
break-even cost. Those measurements can justify a simplification without guessing.

The strongest candidates for a separately approved redesign are the general IPC retransmission
layer, repeated full-model materialization, decoder calibration for small worksets, and broad skin
inheritance if named skins are no longer wanted. Their accepted contracts currently remain in force.
Weighted grouping, FILF ownership, source retention and immutable queues should not be removed
merely because a basic player omits them.
